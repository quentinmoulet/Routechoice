Tracer le parcours à la main

Pour une carte sans lien Livelox : charge l'image (Fichier), calibre l'échelle, puis place les postes ici. 1er point = départ (S), puis les postes 1, 2, 3…, le dernier = arrivée (F). Tape un poste pour le sélectionner, puis glisse-le pour le repositionner.

Importer un parcours (XML IOF 3.0)

Charge d'abord l'image de la carte (Fichier). Le XML positionne les postes via leur position carte (mm) et fournit le géoréférencement (lat/lng) pour le GPX.

Traçage en temps réel

Analyse d'abord la carte (onglet Carte). Place ensuite les postes : dès le 2ᵉ poste, les choix se calculent automatiquement à chaque ajout, et se recalculent quand tu déplaces un poste (au relâché). Clic = ajouter ; glisser un poste = déplacer.

Partager l'événement

Crée un lien qui rouvre ce parcours avec tous les choix calculés (et les corrections au pinceau). Le lien fonctionne tant que le serveur local tourne (même réseau).

Export PDF

Génère une page par tronçon (capture de la carte avec les choix). Analyse d'abord les tronçons voulus (« Tout » dans le bandeau du bas). Dans la fenêtre d'impression, choisis « Enregistrer au format PDF ».

Export GPX (géoréférencé)

Exporte les lignes de chaque choix de tout le parcours en GPX (1 trace par choix). Nécessite une carte géoréférencée (Livelox, XML IOF, ou world file + EPSG).
